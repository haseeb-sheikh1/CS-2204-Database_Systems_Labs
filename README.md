## 🚀 Execution Instructions
1. Ensure **MySQL 8.x** or a compatible environment is running via XAMPP[cite: 1, 4, 6].
2. Navigate into any specific lab folder to access its standalone `.sql` script.
3. Execute the script in **MySQL Workbench** or your command line client; each script automatically handles database creation, table setup, data insertion, and queries.
